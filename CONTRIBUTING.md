# Contributing

1. Fork the repo and branch from `main`.
2. Make the change in conventional Go style, with a test. A bug fix starts with a test that fails without it.
3. Run `make check`. It must pass; CI runs the same target.
4. Open a pull request against `main` saying what changed and why.

Report security issues privately as `SECURITY.md` describes, not in a pull request or issue.
