# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, keep feedback about the work. Harassment, personal attacks and discriminatory language are not acceptable. Maintainers may remove comments, issues and contributions that break this, and ban repeat offenders.

Report a violation to guy@grigsby.dev. Reports are handled privately.
